Backend ↔ Frontend en 30 secondes

BACKEND
Python 3.11+ · FastAPI sous /api/v1/ · Pydantic v2 · SQLAlchemy 2 + SQLite + Alembic · 5 parsers (.docx, .pdf, .xlsx, .xml/S1000D, .csv) · 4 contrôles métier (couverture DMC, renommages Jaccard, cohérence, illustrations) · Mistral API (chat + embeddings RAG + vision multimodale optionnelle) · httpx async + SSE · structlog.
FRONTEND
Preview HTML embarquée dans le backend (sans Node) — vanilla JS · i18n FR/EN/ES · vues Projets · Manager · Rédacteur · Chatbot · Données · Paramètres. Build React + Vite optionnel pour UI plus riche.

Workflow utilisateur

1. Onglet « Projets » → créer un projet (nom + description).
2. Téléverser la référence DMC (.csv/.xlsx) attendue par le client + les fichiers FTM (.docx/.pdf/.xlsx/.xml/S1000D). Versionnage SHA-256 automatique.
3. « Lancer l'analyse » → 4 contrôles séquentiels appliqués à la dernière version de chaque fichier ; les anomalies sont créées avec le statut open.
4. Si Mistral est configuré : indexation RAG (chunking + embeddings) stockée en SQLite, pour permettre le chatbot.
5. Vue Manager : KPIs agrégés du projet. Vue Rédacteur : anomalies groupées par fichier avec suggestions. Chatbot : Q&A RAG avec citations [nom_fichier].
6. Cycle anomalie : open → acknowledged → fixed (résolue) ou rejected (faux positif). Export CSV des anomalies à tout moment.

Règles métier — FTM Agent v4

Le moteur applique les règles métier FTM définies par les experts. Cette page les liste en lecture seule pour transparence. Toute modification passe par l'équipe technique — pas d'édition runtime sur les défauts.
Télécharge un document RULES.md qui reflète l'état actuel du moteur (sections, paramètres, exemples).
Les colonnes Excel du suivi ATM (script, granules) se definissent desormais a l'upload du suivi ATM, dans le detail du projet.

Règles personnalisées (IA)

Règles évaluées par le Mistral embarqué sur chaque FTM analysée. Décris la règle en langage naturel dans « Consigne ». Actives uniquement si Mistral est configuré. Anomalies de type « personnalisee ».
Astuce : dans une consigne, ecris {nom_de_colonne} pour injecter les valeurs d'une colonne de reference du projet (definie dans le detail du projet, carte Referentiels).
