Workflow utilisateur

1. Onglet « Documents » → glisser un ou plusieurs PDFs dans la dropzone et choisir le système d'unités cible. Versionnage SHA-256 automatique.
2. « Lancer l'analyse » → 3 contrôles parallèles (6 règles S1000D/STE built-in + règles custom + conversions d'unités) ; les suggestions sont créées avec le statut open, surlignées sur la page concernée.
3. Vue Rédacteur : suggestions groupées par document et par page. Chaque ligne : original → proposed + sévérité + type. La suggestion est éditable avant Accept.
4. Cycle suggestion : open → accepted → applied (PyMuPDF édite avec auto-shrink/reflow, crée v_{N+1}.pdf) ou rejected.
5. Tableau de bord : KPIs agrégés (PDFs · suggestions ouvertes / appliquées · top documents · répartition par sévérité et par type de règle).
6. Export PDF édité (vN.pdf courant) ou rollback à n'importe quelle version antérieure. EditHistory trace tous les patchs.
